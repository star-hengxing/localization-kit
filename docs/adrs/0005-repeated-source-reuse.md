# ADR-0005: 重复原文与跨版本译文复用边界

日期：2026-11-17 | 状态：accepted

## Context

小说、字幕与游戏语料中存在大量重复文本。若对所有相同原文直接复用译文，虽然能减少 API 请求数，但「うん」「はい」等短应答在不同说话人与语境下的正确译法并不相同，盲目复用会引入语义错误并污染评测数据。

## Decision

采用 **基于完整上下文签名的保守复用**，拒绝按单句原文相等全局扇出：

1. `translate --previous <原作品>` 仅以指定旧作品为复用来源。
2. 机器结果仅在**条目 ID、分组原文、关联术语摘要、模型配置、规则与上文签名**完全一致时才直接复用；任意条件变化则重新触发翻译。
3. 人工修订结果在复用时优先保留；若关联原文或上下文已改变，将其标记为待复核而非静默丢弃。

## Alternatives Considered

- **全局文本级翻译记忆（TM）**：按归一化后的单句原文直接命中复用。在有限样本测试中虽能减少约 13%–16% 请求量，但无法保证多义短句在跨语境下的忠实度。

## Consequences

1. 保证译文结果的可重现性与语境忠实度，不因贪图省请求而牺牲短对白准确性。
2. 如特定调用方确实需要合并完全一致的段落（如游戏重复事件），应在输入预处理层显式去重（参见 ADR-0003），而非在核心层按字符串盲目复用。
