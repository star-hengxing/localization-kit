# ADR-0006: 术语表匹配与按组保守失效

日期：2026-11-17 | 状态：accepted

## Context

本地化既需要跨作品稳定的通用词汇（如常见易误译词与拟声词），也需要随作品变化的人名与专有名词。如果全局隐式加载所有词表，或拟声词按普通子串匹配，单假名条目（如「は」）会误命中助词（如「これは」），造成提示词污染；而术语变更后若全书重翻又会浪费算力并覆盖人工修订。

## Decision

1. **显式配置与覆盖**：`data/glossary/` 提供参考通用词表，作品级术语通过 `config.toml` 或 `--glossary` 显式指定；多表同时加载时按 `src` 由后表覆盖前表。
2. **分类匹配规则**：`term` 与 `name` 类型采用子串匹配；`onomatopoeia` 类型采用**独立词段匹配**（匹配标点/空白分隔的独立词段及其整数次重复），防止单假名误命中助词。
3. **按组保守失效与人工保护**：增量签名包含有序组原文与关联术语摘要。术语增删或变体变更时，仅对应受影响组的机器结果失效；人工修订保留并标为待复核。hard 术语未在译文中出现时记录 `term` 警告，不单独阻断提交。

## Alternatives Considered

- **全量加载内置词表 + 统一子串匹配**：易造成跨题材词义串扰和单假名拟声词误报。
- **术语变更仅重翻单行**：可能丢失同组上下文一致性，难以保证多句间的指代连贯。

## Consequences

1. 维护术语表时应将实际活用形填入 `variants`，并在 `dst` 写入唯一确定译法（避免写入斜杠分隔的多个候选）。
2. 正文中无空格/标点连写的拟声词可能漏命中独立词段规则，需在审校时抽查样本。
3. 导出 VTT / artc 时的后处理同样读取当前配置的术语表。
